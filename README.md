# Ray Tracer

A CPU-based ray tracer written in C++, following Peter Shirley's tutorials

## Current features
- Custom vec3 math library (dot/cross product, unit vectors, operator overloading)
- Ray-sphere intersection
- Virtual camera and viewport projection
- PPM image output with gradient sky background
